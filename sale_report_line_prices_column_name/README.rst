=============================================
Sale Report print – Set column name for Price
=============================================

::

    Set column name for Price in Sale Report print

Configuration
=============
::

    Use Sale Settings

Usage
=====
::

    Go to Sale Settings and set "Use Sale Report Price Name" field as active.
    Then write a custom column name for Price in Sale PDF print.

Known issues / Roadmap
======================
::

    This module should not create any issues with other modules.
    But, as usual, make sure not to have duplicate technical field
    names in use.
