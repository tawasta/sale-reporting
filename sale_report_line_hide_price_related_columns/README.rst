=======================================================
Sale Order Report - Hide price-related columns on lines
=======================================================

* Hides the price details from SO lines, so that only the total 
  is shown below the lines. Columns hidden:

  * Unit price
  * Discount
  * Taxes
  * Line total

Configuration
=============
* None needed

Usage
=====
* Just print a Sale Order
