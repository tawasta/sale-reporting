=============================================
Sale Order PDF print – Hide Discount decimals
=============================================

::

    Hide decimals from discount in lines of sale order PDF print

Configuration
=============
::

    None needed

Usage
=====
::

    Go to Apps and install this module. Print out PDF from a sale order to
    see its changes. The decimals from discounts should be hidden in the PDF.

Known issues / Roadmap
======================
::

    The module has been designed to be compatible with other modules.
