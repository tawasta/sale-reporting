Sale Report Partner overdue interest
====================================

Sale Report Partner overdue interest

Configuration
=============
Odoo settings toggle to enable/disable overdue interest display 
in sale report.

By default module is inactive, to activate it go to Settings, Invoicing and in 
Customer payments section enable "Show overdue interest in sale report" option.

Usage
=====
Install the module and enable the setting as described in Configuration section. 
Then you can see the overdue interest in sale report.
