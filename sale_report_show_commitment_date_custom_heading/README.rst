==================================================
Sale Report Commitment Date - Configurable Heading
==================================================

* Makes the PDF's 'Promised Date' text configurable in settings

Configuration
=============
* Go to sale settings to custyomize the heading text. Note that 
  it is translateable and company-specific in multicompany 
  environments.

Usage
=====
* Just print a quotation / order confirmation to see the 
  custom heading
