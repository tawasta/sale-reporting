============================
Sale Report Product Barcode
============================

* Adds barcodes to the sale order print lines

Configuration
=============
* Using a settings toggle user can enable or disable the showing of 
  scannable product barcodes. Default is disabled, when only numeric values are shown.

Usage
=====
* Install the module from Apps
